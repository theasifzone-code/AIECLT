# AI-ECLT: Project Documentation

## 🚀 Overview
**AI-ECLT (AI-Enabled Exam Center Location & Traffic)** is a modern web application designed to streamline the examination process for both administrators and students. It helps students find their assigned exam centers, provides real-time traffic updates, and suggests the best routes to ensure they arrive on time. For administrators, it provides a powerful dashboard to manage centers, schedules, and monitor system performance.

---

## 🛠 Technology Stack
- **Frontend:** React 19 (Modern Functional Components)
- **Build Tool:** Vite (For lightning-fast development)
- **Styling:** Tailwind CSS (For premium, responsive, and clinical UI)
- **Icons:** Lucide React (For consistent and beautiful iconography)
- **State Management:** React Hooks (`useState`)

## ✨ Key Features

### 👤 Student Portal
- **Exam Center Details:** View assigned center name, address, and code.
- **Dynamic Navigation:** Estimated distance and time to the center.
- **Traffic Intelligence:** Live traffic conditions (High, Moderate, Low) and alternative route suggestions.
- **Reporting Guide:** Displays exact reporting time and seat numbers to avoid last-minute confusion.

### 🔑 Admin Dashboard
- **Center Management:** Add, edit, and track the capacity of examination centers.
- **Analytics & Stats:** Monitor total students, active exams, and pending notifications.
- **System Health:** Real-time monitoring of OCR Processing, Traffic API, and Database status.
- **Notifications:** Send bulk alerts to students regarding exam changes or weather updates.
